EN 30 SECONDES
--------------
C'est une application web = UN SEUL conteneur Docker (Node 20), sans base de
données externe. Elle se connecte à l'API Jira Cloud d'Armonie. Le serveur
sert aussi l'interface web déjà incluse. Le service écoute sur le port 4000.


DÉPLOIEMENT (résumé — détails complets dans le PDF)
---------------------------------------------------
1) Construire l'image :
     docker build -t cpwire:latest .

2) Lancer avec un VOLUME PERSISTANT (important) + les variables :
     docker run -d --name cpwire --restart unless-stopped \
       -p 4000:4000 \
       -v /srv/cpwire/data:/app/data \
       -e JIRA_BASE_URL="https://armonie.atlassian.net" \
       -e JIRA_EMAIL="..." \
       -e JIRA_API_TOKEN="..." \
       -e AUTH_EMAIL="..." \
       -e AUTH_PASSWORD="..." \
       -e PROJECTS="TEDL,PEM,TDSS,PDFP,TMT,PTAF,TBEL,TBAL,PBAL,TIMA,PIMA,PIMA2,TDIA" \
       -e ME="Nicolas Durand" \
       -e TARGET_DONE="Terminé" \
       cpwire:latest

3) Exposer le port 4000 derrière le reverse-proxy interne (HTTPS).

Le volume monté sur /app/data conserve le cache des tickets et les fiches
dossiers d'une mise à jour à l'autre.

Sonde de santé : GET /api/health
